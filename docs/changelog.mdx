<Update label="v0.4.1" description="October 23, 2026">
  ## Cleaner exits and clearer session controls

  - **Clean terminal exits:** Ctrl-C and SIGTERM restore keyboard and cursor
    modes before returning to the shell, including during inference.
  - **Resumable interruptions:** Interrupted TUI sessions remain available for
    explicit resume, with the full session ID and resume command printed on exit.
  - **Quieter Skills:** Identical discovery warnings appear once per Meldra home
    across restarts and resumes. Changed diagnostics still appear.
  - **Clearer policy:** The TUI header shows `Read-only` or `Editing`, with
    `Confirm changes` or `File edits allowed` for the active permission profile.

  **Upgrade note:** From v0.4.0, run `meldra update`, then restart Meldra to use
  these improvements. This patch adds no task-store schema migration. Users on
  v0.3.0 or earlier should follow the [upgrade guide](upgrading.md).

  [Release and downloads](https://github.com/ruhuang2001/meldra/releases/tag/v0.4.1)
  · [Full changes](https://github.com/ruhuang2001/meldra/compare/v0.4.0...v0.4.1)
</Update>

<Update label="v0.4.0" description="October 22, 2026">
  ## Guide foreground work with explicit context and controls

  - **Project context:** Load scoped `AGENTS.md` instructions and attach explicit
    file references, with a file picker in the TUI.
  - **Execution boundaries:** Inspect in Plan mode, then implement in Build mode
    with explicit workspace permissions.
  - **Foreground controls:** Steer or queue requests, stop a turn without leaving
    chat, and inspect managed commands and recovery evidence.
  - **Updates:** Install checksum-verified stable releases with `meldra update`
    and receive cached release notices.
  - **Certificate security:** All four release binaries use Go 1.26.10, including
    the fix for GO-2026-6809 / CVE-2026-111943.

  **Upgrade note:** v0.3.0 and earlier do not provide `meldra update`; use the
  installer or a verified platform archive. Stop all Meldra processes and back
  up the complete private `MELDRA_HOME` before first opening the new ledger.
  Schema 1 migrates to schema 2; rollback requires the previous binary with the
  pre-upgrade backup or a separate data directory. Restart existing processes
  to use the new binary and security fix.

  [Release and downloads](https://github.com/ruhuang2001/meldra/releases/tag/v0.4.0)
  · [Full changes](https://github.com/ruhuang2001/meldra/compare/v0.3.0...v0.4.0)
</Update>

<Update label="v0.3.0" description="October 10, 2026">
  ## Connect MCP tools and load Skills on demand

  - **MCP integration:** Connect external MCP servers or expose Meldra's workspace
    tools through its MCP server workflow.
  - **On-demand Skills:** Discover local workflow packages and load their
    instructions and resources when needed, without preloading every skill.
  - **Reliability fixes:** Improved MCP validation, OAuth callback shutdown,
    Linux terminal input handling, and recovery of streamed assistant output.

  [Release and downloads](https://github.com/ruhuang2001/meldra/releases/tag/v0.3.0)
  · [Full changes](https://github.com/ruhuang2001/meldra/compare/v0.2.0...v0.3.0)
</Update>

<Update label="v0.2.0" description="October 9, 2026">
  ## Inspect execution history and recover explicitly

  - **Durable tasks:** Persist task records and execution ownership instead of
    relying only on conversation snapshots.
  - **Foreground recovery and controls:** Inspect interrupted work and explicitly
    continue it, with controls for foreground execution.
  - **Safer persistence:** Stop execution after session snapshot failures and
    preserve evidence across recovery and provider replay boundaries.

  **Upgrade note:** Back up the full Meldra state directory before migrating or
  downgrading. Legacy conversation snapshots are not a replacement for the task
  ledger. See the [upgrade and downgrade guide](upgrading.md).

  [Release and downloads](https://github.com/ruhuang2001/meldra/releases/tag/v0.2.0)
  · [Full changes](https://github.com/ruhuang2001/meldra/compare/v0.1.0...v0.2.0)
</Update>
