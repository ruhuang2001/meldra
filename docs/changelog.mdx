<Update label="v0.3.0" description="October 10, 2026">
  ## Connect MCP tools and load Skills on demand

  - **MCP integration:** Connect external MCP servers or expose Meldra's workspace
    tools through its MCP server workflow.
  - **On-demand Skills:** Discover local workflow packages and load their
    instructions and resources when needed, without preloading every skill.
  - **Reliability fixes:** Improved MCP validation, OAuth callback shutdown,
    Linux terminal input handling, and recovery of streamed assistant output.

  [Release and downloads](https://github.com/ruhuang2001/meldra/releases/tag/v0.3.0)
  · [Full changes](https://github.com/ruhuang2001/meldra/compare/v0.2.0...v0.3.0)
</Update>

<Update label="v0.2.0" description="October 9, 2026">
  ## Inspect execution history and recover explicitly

  - **Durable tasks:** Persist task records and execution ownership instead of
    relying only on conversation snapshots.
  - **Foreground recovery and controls:** Inspect interrupted work and explicitly
    continue it, with controls for foreground execution.
  - **Safer persistence:** Stop execution after session snapshot failures and
    preserve evidence across recovery and provider replay boundaries.

  **Upgrade note:** Back up the full Meldra state directory before migrating or
  downgrading. Legacy conversation snapshots are not a replacement for the task
  ledger. See the [upgrade and downgrade guide](https://github.com/ruhuang2001/meldra#upgrade-and-downgrade).

  [Release and downloads](https://github.com/ruhuang2001/meldra/releases/tag/v0.2.0)
  · [Full changes](https://github.com/ruhuang2001/meldra/compare/v0.1.0...v0.2.0)
</Update>
