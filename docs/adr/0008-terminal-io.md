# Terminal ownership and bounded output

One input reader owns prompts, approvals and forms. A shared buffered reader preserves piped follow-up lines. Busy controls intercept only explicit commands. Return late input to the ordinary queue if the turn has closed. Bubble Tea owns raw-terminal restoration. Keep terminal output open through shutdown and join input before closing the device. Track pending submissions across delayed Ready events. Bind the displayed result and approval to its actual operation.

Drain command pipes independently of UI speed. Coalesce live notifications, retain a bounded log tail and private spool, and keep draining after a log write fails. Replay sanitizer state from a bounded checkpoint when a byte cursor begins inside an escape. Keep incomplete UTF-8 for the next read. Serialize callbacks with close. Bound cleanup of detached descendants and use process-group cancellation because direct-child cancellation can leave inherited descriptors live.

Use descriptor-local deadlines with an independently opened file description when possible. Linux procfs can supply independent flags. Duplicating an already nonblocking descriptor is safe. A fixed relay with a liveness pipe handles inherited blocking pipes that cannot be reopened independently. Terminate its group even on abrupt owner exit. Preserve the caller's descriptor flags and obtain terminal identity without switching its descriptor back to blocking mode. Arbitrary embedding writers use ordinary synchronous output because a blocked worker cannot be joined safely. Handle partial writes by reporting a gap once and preserving the first failure for exit status. Tests exercise full pipes, coverage-instrumented children and signal cleanup with bounded ownership.

Sanitize untrusted terminal controls and invalid UTF-8 before presentation. Bound sanitizer state even across split escapes. Send first tokens promptly, then coalesce updates. Keep process output associated with its originating entry as cached transcript segments change. Wrap text to viewport width, expose the real cursor position, and choose readable composer colors. Request wheel events in the alternate-screen chat so scrolling reaches the history viewport; native text selection uses the terminal's mouse override. Selected references retain their structured path. Present complete approval arguments, per-turn usage and calibrated context estimates through prompt-returning event sinks. The JSON stream has its own stable schema, independent of UI and ledger structures.

Distinguish normal EOF on piped input after a prompt from a real controlling-terminal hangup. Integration fixtures close the master of a real PTY to let the OS deliver the signal. Surface tool follow-up activity even when a gateway omits the next progress event. Display the agent-reported mode alone in the composer border. Fitting it within the existing frame preserves IME cursor coordinates and minimum-width layout. Round abbreviated usage counts half up and wait for real usage before showing the footer.
