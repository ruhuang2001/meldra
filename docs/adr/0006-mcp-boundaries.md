# MCP transport and evidence

MCP startup trust comes from user-owned configuration. Persist a digest of the effective binding and resolve executable identity with the same working directory as the launch. Check the binding before connecting because stdio startup can itself perform effects. Bound encoded tool definitions and reserve provider slots for built-ins. Keep readable tool names and use a digest to disambiguate lossy mappings. Discover catalogs on demand. If a legacy server exits on the modern discovery probe, restart the process for its legacy handshake.

A catalog request authorizes that operation on the named server. A prompt remains user input. Schema resolution disables remote references. Validate numeric values without rounding, retain native integer precision on the wire, and accept only primitive form fields and supported titled enums. Escape terminal control characters while keeping CLI JSON round-trippable. Redact transport diagnostics that could expose credentials or server text.

Server protocol owns stdin and stdout. Present approvals through the client and join interaction callbacks before returning input ownership. Cache a protected descriptor for cancellation, accommodate regular files that epoll cannot monitor and preserve read-ahead when a cancelled reader must be replaced. Bind multi-request approvals to all resolved targets and scoped instructions. Hold the operation lock across validation and execution. A failed redemption consumes the token. Human review time is outside the command deadline. Shut down descendants before waiting on readers they may have inherited.

Fetch OAuth tokens at HTTP request time so cancellation bounds refresh even when the SDK detaches its connection context. Keep pending credentials in memory until connection succeeds. Serialize refresh and logout across processes and compare generations before accepting in-flight logins. Complete callback responses before closing connections. An empty state root supports existing MCP clients while private directory validation still precedes file reads.
